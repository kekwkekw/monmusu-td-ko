# UI 표시·폰트 외곽선 수정 기록

2026-11-16~19에 로컬 게임에서 확인한 UI 표시 수정을 기록한다. BepInEx 6 / IL2CPP / MonmusuMod 0.4.0에 적용했으며, 지정 런처를 사용하고 XUnity는 비활성 상태로 유지했다. 이 변경은 정식 릴리스가 아니다.

## 변경

| 대상 | 수정 |
| --- | --- |
| 편성·보조 스킬 | 고정 한 줄 슬롯과 카드명의 과도한 세로 마진을 제거해 이름이 사라지거나 과도하게 축소되는 현상을 수정 |
| 공통 제목 | 세로 여유와 좌우 여백을 확보하고 긴 제목에만 자동 축소 여유를 제공 |
| EX 설명 | 확인된 본문 경로의 하단 마진을 제거하고 원래 행간에서 20을 줄여 긴 설명의 가독성을 개선 |
| 종족 특성·무기 | Setup 두 overload에서 승인된 종족 특성 접두사를 연결하고, `武器種 :` 번역을 `무기 :`로 정정 |
| 도움말 Master | native 배열 외에 IList/ICollection도 순회하고 boxed value-type 변경을 원래 collection에 기록. 지원하지 않는 collection은 경고 |
| 동적 날짜 | 시즌패스는 승인된 `{0}일까지` 서식을 해당 renderer에서 사용하고 전투 기록 날짜는 해당 경로에서만 `yyyy-MM-dd`로 표시 |
| 날짜 서식 | 실행용 `yyyy/MM/dd`를 `keep_source`로 정정. workflow에서 날짜·시간 서식 번역을 거부하고 DLL도 이전 CDN의 잘못된 서식 치환을 건너뜀 |
| 짧은 라벨 | 퀘스트의 `진행`, `권장 Lv:`, 목장의 `유닛 EXP :`를 확인된 경로에서만 표시 |
| 한글 폰트 | 일반 UI RHR Bold와 원본 Kurokane용 Maple Bold fallback을 분리. 본문·백로그용 선택적 Unity Font bundle도 보존 |
| 줄바꿈·빈 버퍼 | modern Hangul line breaking을 사용하고 null TMP 숫자 버퍼의 예외를 수정 |

원문·제어 태그·Novel 행·Names·HOLD 정책은 변경하지 않는다. 표시 축약은 정본 문자열을 다시 저장하지 않고 해당 UI 경로에서만 수행한다. UI/Master 검수 결정의 변경은 무기 라벨과 실행용 날짜 서식 두 행뿐이다. 배포 UI는 1,183쌍, Master는 기술 서식 1쌍을 제외한 74,566쌍이다.

## 외곽선

원본 일반 UI는 흰 글자에 짙은 회갈색 SDF 외곽선을 사용한다. 확인된 원본의 outline/dilate 0.26/0.26을 기준으로 RHR 후보를 실기 비교했고, 최종은 다음과 같다.

| 항목 | 값 |
| --- | --- |
| Face | 흰색 `#FFFFFF` |
| Outline | 짙은 회갈색 `#504646` |
| Outline width / Face dilate | 0.36 / 0.36 |
| Outline softness | 0.02 |

TMP 외곽선은 글자 안쪽도 차지한다. dilate를 0으로 둔 후보는 작은 한글의 흰 획이 가늘어져 제외했다. 0.44/0.44도 비교했으나 테두리 비중이 커 최종값으로 선택하지 않았다. 이 수치는 px가 아니며, 모든 해상도에서의 최적값을 입증한 것은 아니다.

EX 제목·본문, 편성 장착 보조 스킬명, 보조 스킬 카드명, 수신 상세 스킬, 도감 보이스 버튼에 renderer별 복제 재질을 적용한다. 공유 폰트·아틀라스 재질을 직접 수정하지 않고, 한글이 없는 문자열로 재사용되면 원래 재질로 돌아간다. 비활성 vertex 색/alpha는 유지한다. Maple 장식 버튼은 원래 outline/dilate 0.20/0.20과 underlay를 유지한다.

## 실기 근거와 한계

11월 17일 수정 후 31개 화면 상태, 11월 19일 외곽선 비교 23개 캡처를 확인했다. 서로 다른 메뉴 54개나 게임 전체의 전수 검사를 뜻하지 않는다. 원본 게임·계정 화면·개인 로그·진단 DLL은 공개하지 않는다.

| 대상 | 확인 결과 |
| --- | --- |
| 편성 팀 1 | 장착 보조 스킬 8개가 크기 17·1줄·overflow=false. 재진입 후 유지 |
| 보조 스킬 목록·인벤토리 | 카드명 크기 14 복원. 금색·붉은 카드와 비활성 상태 확인 |
| 돌세라 EX | 11.7→13.1, 4줄·72문자·overflow=false |
| 프로필 긴 EX | 10.95→12.7, 4줄·103문자·overflow=false. 나머지 두 EX는 14·3줄 |
| 긴 공통 제목 | 16.4·1줄·overflow=false로 뒤로/도움말 버튼 사이에 표시 |
| 종족 설명 | 5줄 유지, 스크롤로 마지막 문장 접근 확인 |
| 도움말 | native Master 3,938필드 적용 및 한국어 제목 확인. 이미지 본문은 별도 |
| 수신·보이스 | 주황 패널 본문 2개는 14·2줄·overflow=false. 밝은 보이스 버튼의 글자 경계 확인 |
| Maple | 실제 Maple glyph, 원래 외곽선·underlay 유지 확인 |

수신 제목과 개행을 유지한 작은 진행 라벨은 기존 Overflow 모드의 내부 `isTextOverflowing=true`가 남는다. 전체 문자가 표시됨을 확인했으며, 모든 renderer의 overflow 플래그가 false라고 주장하지 않는다. 긴 EX 전체를 크기 14로 보장하지도 않는다.

최종 두 실행에서 UI/Master 실패, Master field missing, TMP 누락 글리프, startup 실패 로그는 0건이었다. 11월 19일 비교 중 재화·스태미나 소비는 없었다. 게임 종료 후 임시 진단 DLL을 제거했고 설정은 유지했다. 설치된 본문은 사용자 비교 요청에 따른 RHR Bold이며, 11월 2일의 최초 Medium 선정과 구분한다.

| --- | --- |
| MonmusuMod.dll | `3af52e9ce9e1aaed6d9bb1f45a2d5ea62f00da309912e1c35475c3ff3a004d2f` |

실기 당시 공개 manifest는 `a42f1831246efd41e1bea457637f0511586d01cdc9c467a0fc850d22a38a4f8b`다. 이번 승인으로 게시하는 두 번역 정정의 manifest는 `511c1daa5915f791a42fcbd0586ae3c4b80221b7d8ca75bc9563eb57dbf60d6e`다. 새 CDN 세대의 게임 수신은 이 실기 기록에 포함하지 않는다. DLL에는 이전/새 CDN에 대한 호환 처리가 있다.

## 병합 전 검사

최신 main 기반의 별도 체크아웃에서 Python 3.14 preflight 50개, UI workflow 8개, 이미지 catalog 3개, grid index 2개가 통과했다. 공개 파일의 결정·원문과 manifest 해시 일치 검사도 통과했다. native hook wrapper 23개를 정적으로 확인했고 플러그인 빌드는 오류·경고 0건이다. .NET 6 테스트 프로젝트의 SDK 지원 종료 안내는 별도로 남는다.

Core 합성 회귀 31개와 공개 패키지 검사 2개, 합계 33개를 통과했다. 공개 패키지 전체 4,146장면·한국어 159,817행·HOLD 17행·Names 776건을 eager/lazy 경로에서 대조했다. 이 명령은 게임 설치·실행·API 호출을 하지 않는다. 외곽선 자체는 위의 실기 비교로 검증했으며 색상 상수를 그대로 반복하는 단위 검사는 추가하지 않았다.

## 남은 작업

1. **최신 원문 차분 수집·번역·검수:** 현행 이벤트/상품, `ネリカ`·`カンリネ`·`ツガリ` 등의 신규 원문, `ほうき` 단독 아이템명이 기존 스냅샷에 없다(QA-005). 유사한 옛 원문을 대신 매칭하지 않고 기존 번역 파이프라인으로 처리한다.
2. **이미지 후속 번역:** 전량 비트맵 선별은 완료했지만 OCR/경로 후보가 곧 번역 확정 대상은 아니다. 첫 정본 10개는 적용·실기 확인했고, 의상 변경·장비·잠재 각성 등 나머지 이미지 문구는 제작·검수·적용이 남아 있다.
3. **직접 전투 QA(QA-012):** 배치 칸에 click/drag해도 유닛 배치가 반응하지 않았다. 일시정지·리타이어와 리플레이는 반응했으며 입력 도구/게임/모드 중 원인은 미확정이다. 직접 배치, 스킬 상세, 실보상 확인이 남았다. UI 예외가 원인이라고 단정하지 않는다.
4. **추가 표시 회귀:** 더 긴 스킬·다른 캐릭터·해상도와 아직 방문하지 않은 메뉴를 확인한다. 새 한글이 들어오면 정적 TMP 아틀라스 corpus를 갱신한다.
5. **정식 배포 준비:** 사용자 요청 시 최종 폰트·이용 조건·설정·이미지·CDN snapshot을 묶고, 깨끗한 설치/업그레이드/제거와 실제 게임 수신을 확인한다. 현재 버전은 0.4.0 로컬 보정본이며 release 게시를 뜻하지 않는다.

Novel 4,146장면의 기존 번역 및 승인 HOLD 17행은 유지한다. API 초벌 확대는 보류 상태이며 이번 UI 수정에서 파이프라인을 변경하지 않았다.
