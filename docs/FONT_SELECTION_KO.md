# 폰트 선정 상태

2026-11-02 사용자 결정으로 다음 세 역할의 한글 서체를 확정했다.

| 역할 | 확정 서체 |
| --- | --- |
| 시나리오 본문 | Resource Han Rounded KR Medium (RHR Medium) |
| 일반 UI | Resource Han Rounded KR Bold (RHR Bold) |
| 장식 텍스트 | 메이플스토리 Bold |

원본 Kurokane를 사용하는 프로필·능력치 버튼과 향후 장식 메뉴 현지화에는 메이플스토리 Bold를 기준으로 한다. 이미지에 들어 있는 글자는 원본의 조형과 용도에 따라 이 역할 구분을 적용한다.

일반 메뉴, 확인창, 시스템 안내, 목록·도감의 설명처럼 읽는 텍스트는 RHR Bold를 기준으로 한다. 같은 화면에서도 Kurokane 계열 버튼처럼 장식 역할인 요소만 메이플스토리 Bold를 사용한다. 번역 검수 파일에는 표시 문구만 기록하고, 폰트는 렌더러의 표시 역할에 따라 선택한다. UI 번역에서 글꼴 적용을 위해 원문에 없던 태그를 추가하지 않는다.

실기 비교 자료와 초벌 문구는 로컬 `work/font-ab-20261102/`에 보관한다. 촬영을 위한 폰트 적용은 임시이며, 촬영 후 기존 설치 상태로 복원한다. 이 문서는 서체 선정 기록이며 정식 배포용 폰트 번들·이미지 에셋이 완성되었다는 뜻은 아니다.
